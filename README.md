## 📖 Sobre o Projeto

**Jogo da Cobrinha Carioca** é uma releitura do clássico "Snake Game" com um toque brasileiro. Desenvolvido inteiramente em JavaScript puro (vanilla JS), HTML5 e CSS3, esse jogo traz uma estética moderna e animações fluidas que o tornam viciante e divertido.

A "Cobrinha Carioca" se destaca pelas suas cores vibrantes, design visual atraente, e pela forma como a cobra e a comida são renderizadas de maneira única e detalhada.

## ✨ Funcionalidades

- 🎮 Controles intuitivos usando setas direcionais ou WASD
- 🏆 Sistema de pontuação com recorde local
- ⚡ Aumento de velocidade progressivo conforme a pontuação sobe
- 🔁 Função de pausa integrada (tecla espaço)
- 🎨 Design visual moderno e atraente
- 🦎 Cobra com olhos animados que seguem a direção do movimento
- 🍎 Comida renderizada como uma maçã detalhada
- 🌿 Cenário com estilo "grama" para melhor imersão

## 🎮 Como Jogar

1. **Controles:** Use as teclas de seta (↑, ↓, ←, →) ou WASD para direcionar a cobra
2. **Objetivo:** Comer as maçãs para crescer e acumular pontos
3. **Desafio:** Evite colisões com as paredes e com o próprio corpo da cobra
4. **Dificuldade Progressiva:** A velocidade da cobra aumenta a cada 50 pontos!

## 💻 Tecnologias Utilizadas

- **HTML5 Canvas:** Para renderização em tempo real do jogo
- **CSS3:** Para estilização e efeitos visuais
- **JavaScript:** Para toda a lógica do jogo e interações
- **LocalStorage API:** Para salvar o recorde local (em implementação)

## 🛠️ Instalação e Execução

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/jogo-da-cobrinha-carioca.git
   ```

2. Navegue até a pasta do projeto:
   ```bash
   cd jogo-da-cobrinha-carioca
   ```

3. Abra o arquivo `index.html` no seu navegador preferido ou use um servidor local:
   ```bash
   # Usando Python para criar um servidor local simples
   python -m http.server 8000
   # Ou usando o Live Server do VS Code
   ```

## 🔧 Personalizações Possíveis

Você pode facilmente personalizar diversos aspectos do jogo:

- **Cores:** Modifique as variáveis de cor no CSS
- **Velocidade:** Altere o valor inicial de `gameSpeed` no JavaScript
- **Tamanho do Grid:** Ajuste o valor de `gridSize` para mudar o tamanho da cobra e da comida
- **Dimensões do Canvas:** Modifique a largura e altura do elemento `#game-board`
